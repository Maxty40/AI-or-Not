# AI OR NOT - A Simple Image Guess Mini-Games

Is it AI? Or not? Guess it!
Given 5 pictures randomly, your task is guess the image generated by AI or not, simple as that!

*This App Made using Google AI Studio*

*View this app in: ai-or-not-pink.vercel.app*

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
